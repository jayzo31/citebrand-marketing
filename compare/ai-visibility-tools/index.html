How to tell a fixer from a scoreboard

A scoreboard tells you that you are losing. A diagnostic tells you what to change. CiteBrand's homepage puts the difference as "A Thermometer vs. a Surgeon": a thermometer says "Your visibility is low. Forbes matters." A surgeon says "You're missing from this Forbes URL. Your competitor is mentioned in paragraph 3. Here's the author's contact. Here's exactly what content to create." Whatever tool you trial, run one of your own prompts through it and apply four checks:

  1. Does it name the cited URL? Not "Forbes matters" but the specific page the AI answer cites for a competitor. Vendor wording that addresses this: Peec AI "Find Key Sources", Ahrefs Brand Radar "find opportunities to get mentioned", CiteBrand "Find the exact URLs where competitors are cited but you're not".
  2. Does it name the missing page type? For example, the AI cites comparison tables and you only have blog posts. CiteBrand's Intent Mismatch Detection: "AI wants comparison tables but you have blog posts? We show the content format that wins."
  3. Does it name a technical blocker? For example, AI search crawlers blocked in robots.txt, or page text that only appears after JavaScript runs. Vendor wording that addresses this: Semrush "Site audit for AI readiness", Otterly.ai "Content Audit".
  4. Does it give an owner or a next step? A contact, a page to create, or a change to ship. Vendor wording that addresses this: HubSpot AEO "Get clear recommendations", Writesonic GEO "Action Center" and content agents, Okara AI CMO "Executes: GitHub PRs, CMS publishing", CiteBrand "Get a prioritized list of specific URLs, content, and actions to take".

A tool that passes none of the four is a scoreboard, which is still useful for trend reporting. Because the same prompt returns the same brand list less than 1% of the time across runs, any score should be a mention frequency across repeated samples, not a single rank (SparkToro).

How to evaluate any AI visibility tool

  • Measure frequency, not rank. The same prompt returns the same brand list less than 1% of the time across runs, so a tool should report how often you appear across repeated samples (SparkToro).
  • Ask whether it checks the consumer app or the API. For ChatGPT, API answers and consumer-app answers share only about 24% of brands and 4% of sources (Surfer). Peec AI states that it scrapes real chat interfaces.
  • Don't use Google rankings as a proxy. Only about 12% of URLs cited by AI assistants rank in Google's top 10 for the same query (Ahrefs).
  • Check Bing, not only Google. About 87% of SearchGPT citations matched Bing's top 20 results (Seer Interactive).

What tends to change AI citations

  • Freshness. AI-cited content is about 26% fresher than organic results, and the median citation half-life is about 4.5 weeks (Ahrefs freshness study, via NoGood; Scrunch/Stacker citation half-life study). Keep a visible updated date and refresh key pages.
  • Third-party lists. Third-party "best of" lists win about 81% of listicle citations versus 19% for brand-owned lists (Ahrefs). Being included on independent lists counts, not only publishing your own.
  • Crawlable, server-rendered pages. AI search crawlers need to be allowed in robots.txt and able to read your text without running JavaScript.
  • llms.txt and JSON-LD are hygiene only. llms.txt showed no correlation with AI citations across about 300k domains, and Google states it does not use it (SE Ranking). JSON-LD schema showed no measurable AI-citation lift in a controlled study; keep it for classic rich results (Ahrefs).
